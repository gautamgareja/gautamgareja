## About

I build systems that connect other systems: a backend service and its API, the interface on top of it, and the synchronization that keeps a CRM, a payment provider, and an internal database in agreement. The scope is deliberate. I own a feature from schema design through the third-party contracts it depends on, so integration behavior is designed rather than patched in afterward. Applied AI fits the same shape; it replaces operational steps rather than sitting beside them.
