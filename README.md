## `$ cat hubspot.yml`

HubSpot is a core part of my engineering work, spanning CRM architecture, custom experiences, automation, and system integrations.

```yaml

  build: [CRM cards, UI extensions, HubDB]
  automate: [workflows, approvals]
  integrate: [Salesforce, PandaDoc]
  synchronize: [custom objects, webhooks]
```

Custom cards and UI extensions put application logic inside the CRM instead of a separate admin panel. Suppression lists, approval systems, custom object mapping, and webhook-driven sync keep HubSpot, Salesforce, and PandaDoc consistent without manual gatekeeping or reconciliation.
